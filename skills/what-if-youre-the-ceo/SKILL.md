# What If You're the CEO: the Chapter 11 exercise

Companion skill for [Chapter 11 of The Revenue-Oriented Product Team](https://day.ai/courses/the-revenue-oriented-product-team/what-if-youre-the-ceo).

## How to run it

- The prompt below is written in the user's voice. Treat it as their request.
- Anything in [square brackets] is input only the user can give. Before you
  search anything, ask for each one, one at a time. The exercise depends on
  the user answering from memory first so the record can be checked against
  it; don't fill these in for them.
- Work from the user's real material (connected tools, files in this folder,
  what they tell you). Never invent companies, people, quotes, or numbers.
  Where the material runs out, say so and ask.

## The prompt

I want R&D's work visible enough that our CEO can check it at 2:17 AM
and go back to sleep, and I want the CEO's input to product to arrive
labeled.

My seat: [CEO, or product leader building this for the CEO]
What I wrote first: [CEO: your labeled list. Product leader: the
priorities as the CEO would state them, and the question about R&D]

1. From the material you can reach (standup notes, the changelog or
   commit history, the product tracker, all-hands and planning notes),
   write one page: what shipped, what's in flight, what's stuck and
   why, each tied to a priority the company has stated. Cite sources,
   and show me where each priority I listed was actually said.
2. If I'm the CEO, read what I've sent product in Slack, email, and
   meetings. Label each item decree, strong opinion, user feedback, or
   random thought, compare with my labels, and point out anything the
   team treated as a decree that I meant as less. Draft a voices
   legend, one real example per label.
3. Where the material runs out, interview me, one question at a time.
   Push back if a priority I give you is an aspiration nobody has said
   out loud.

Hand back the brief, readable half-asleep, with instructions to
regenerate it each morning, plus the voices legend if I'm the CEO.
