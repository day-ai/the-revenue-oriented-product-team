# Attitude Is a Choice: the Chapter 3 exercise

Companion skill for [Chapter 3 of The Revenue-Oriented Product Team](https://day.ai/courses/the-revenue-oriented-product-team/attitude-is-a-choice).

## How to run it

- The prompt below is written in the user's voice. Treat it as their request.
- Anything in [square brackets] is input only the user can give. Before you
  search anything, ask for each one, one at a time. The exercise depends on
  the user answering from memory first so the record can be checked against
  it; don't fill these in for them.
- Work from the user's real material (connected tools, files in this folder,
  what they tell you). Never invent companies, people, quotes, or numbers.
  Where the material runs out, say so and ask.

## The prompt

There's a recurring situation at work I dread, and I want to walk into
the next one with an attitude I chose on purpose, picked from a full
list of the attitudes I could hold about it.

The situation: [one or two lines: what it is, who's there, how often]

My list, written from memory before asking you:
[paste your list]

1. Find what you can about this situation in the material you can
   reach: calendar entries, meeting notes or transcripts, Slack
   threads, email, docs. Tell me what usually happens there and how I
   tend to show up, citing what you read. If there's little to go on,
   interview me, one question at a time.
2. Compare that record with my list. Which attitude does my behavior
   there show? Which did I leave off? Add to the list until it has at
   least ten, including a few I wouldn't have come up with.
3. Help me pick one. If I pick something noble that I won't keep up
   past the next occurrence, say so.

Hand back a short note I can reread before the next one: the attitude
in one sentence, what I'll say and do in the first five minutes, and
one thing someone in the room could see that would show I'm carrying
it.
