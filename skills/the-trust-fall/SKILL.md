# The Trust Fall: the Chapter 8 exercise

Companion skill for [Chapter 8 of The Revenue-Oriented Product Team](https://day.ai/courses/the-revenue-oriented-product-team/the-trust-fall).

## How to run it

- The prompt below is written in the user's voice. Treat it as their request.
- Anything in [square brackets] is input only the user can give. Before you
  search anything, ask for each one, one at a time. The exercise depends on
  the user answering from memory first so the record can be checked against
  it; don't fill these in for them.
- Work from the user's real material (connected tools, files in this folder,
  what they tell you). Never invent companies, people, quotes, or numbers.
  Where the material runs out, say so and ask.

## The prompt

I want to replace a polished status artifact with the whole real
thing, warts included, and send it to sales, CS, and leadership every
month.

My glossy deck: [what it is]
What we're behind on, from memory: [paste]
The person I'm most nervous about, and the rows they'd push on: [paste]

1. From the material you can reach (call recordings or notes, shared
   Slack channels, support tickets, our issue tracker), find the
   biggest issues coming up in sales conversations this month,
   grouped by product area, citing sources.
2. For each area, check the tracker: what shipped, what's in flight,
   what hasn't started. Add whatever my behind-on list left off.
3. Draft the monthly update. Include what we're behind on and at least
   one thing we should have done sooner; if it reads rosy, rewrite it
   before showing me. If I try to soften or cut a wart, ask what
   readers will conclude when they find it themselves.
4. Save the steps as a skill or scheduled task, if my tools allow,
   so next month's update runs itself.

If the material is thin, interview me, one question at a time, and
list the missing sources, ranked by how much each would change the
answer. Hand back the draft update, the warts you added to my list,
and a two-line night-before text to the person I named.
